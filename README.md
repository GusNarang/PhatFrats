# PhatFrats

A party finder for Penn State students, built by **Agastya Narang**.

Log in with a Penn State email and get a map of every Interfraternity Council house around State College, with this week's parties lit up. Click a house to see the theme, time, dress code and how full it's getting, then request an invite right from the page. A directory of all 34 IFC chapters, with addresses and Instagram handles, is open to everyone.

## Features

- **Students-only login** with an `@psu.edu` email (demo only: no password, saved in your browser)
- **Party map** of real State College streets with 31 houses pinned at their addresses, with zoom and pan, filterable by night and vibe
- **Party details** with a hype meter, a Google Maps link to the address, and the chapter's Instagram
- **Invite requests** with plus-ones and a note, tracked under My invites
- **House directory** of all 34 chapters, with search and sorting
- **Party smart** safety tips

## Run it

It's a single file with no build step. Open `index.html` in a browser, or turn on GitHub Pages for the repo (Settings → Pages → deploy from the `main` branch).

- Chapter names and addresses come from [pennstateifc.org/chapters](https://www.pennstateifc.org/chapters).
